【⚠️ 极简警告】
1. C 语言版无 GUI，全为终端操作。编译高度依赖环境。
2. 如果机房电脑没网、没装 libssl-dev，会直接编译报错。
3. C 语言版仅作为“锦上添花”展示底层功底，如果机房编译不过，果断切回 Python 版！
4. 所有 C 语言操作只在 Ubuntu 20.04 下进行。

--------------------------------------------------
第一部分：环境准备与编译 (提前做)
--------------------------------------------------

[环境: Ubuntu 20.04] 1. 安装 C 编译环境与加密依赖
--------------------------------------------------
sudo apt update
sudo apt install -y build-essential libssl-dev

[环境: Ubuntu 20.04] 2. 编译 C2 破解程序 (注意必须加 -lcrypt 参数)
--------------------------------------------------
gcc crack_c.c -o crack_c -lcrypt

[环境: Ubuntu 20.04] 3. 编译 C1 聊天程序 (注意必须加 -lssl -lcrypto -lpthread 参数)
--------------------------------------------------
gcc chat_c.c -o chat_c -lssl -lcrypto -lpthread


--------------------------------------------------
第二部分：测试数据准备 (复用 Python 版的数据)
--------------------------------------------------

* 说明：直接复用之前生成的 ~/Desktop/shadow.txt (真实密码 dees) 和 words.list。
* 密钥文件：C 语言读取密钥不挑格式，直接复用 Python 生成的 key.bin 和 badkey.bin 即可。

--------------------------------------------------
第三部分：任务一 C2 - C语言密码破解
--------------------------------------------------

【功能特色】纯 C 实现，包含字典匹配、暴力穷举、自动生成 logs 文件夹归档。

[环境: Ubuntu 20.04] 运行指令 (开一个终端)
--------------------------------------------------
./crack_c ~/Desktop/shadow.txt words.list

【预期结果】
1. 程序首先进行字典攻击。
2. 提示“[-] 字典未命中”，随后进入“阶段二：开始 1-4 位小写字母暴力穷举”。
3. 几秒钟后输出：[🎉 成功] 账号 [seed] 的密码是: dees
4. 并提示日志已保存至 logs/crack_c_log_时间.txt

--------------------------------------------------
第四部分：任务二 C1 - C语言加密聊天
--------------------------------------------------

【功能特色】底层 Socket 多线程、OpenSSL AES 加密、错误密钥解密失败。

[环境: Ubuntu 20.04] 运行指令 (需要开两个终端并行)
--------------------------------------------------

终端 1 (服务端，等待连接)：
./chat_c server key.bin

终端 2 (客户端，正常通信)：
./chat_c client key.bin

终端 2 (客户端，演示错误密钥，高分时刻)：
./chat_c client badkey.bin

【预期结果】
1. 正常连接时，互发消息能成功显示“[收到密文并解密]”。
2. 使用 badkey.bin 连接时，服务端发消息，客户端会立刻提示“[⚠️ 解密失败！密钥不匹配]”。

--------------------------------------------------
第五部分：机房实操避坑指南
--------------------------------------------------
1. 如果运行 ./crack_c 报 "Segmentation fault"，说明代码漏了 stdarg.h 头文件或 va_list 使用错误（当前代码已修复，请放心使用）。
2. 如果编译时提示 "undefined reference to crypt"，说明漏了 -lcrypt 参数。
3. 如果运行 ./chat_c 提示无法打开密钥，请检查当前路径下是否有 key.bin。
4. 演示结束后，记得把桌面上的 shadow.txt 删掉，保护系统安全。
