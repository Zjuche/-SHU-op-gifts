<h1 align="center">O P 语 录</h1>

我的数据库1是sap老师的。个人认为课程的实验作业还是比较容易，毕竟你用AI就可以把这些SQL命令都生成出来了，上机作业还是比较容易完成的。

sap老师不要求写实验报告，不过会要求你把实验的截图放在实验题目的文档里面，到最后的时候学习通提交上去。

SQL如果装在自己的电脑上，会比较大，而且不容易清理，建议用容器，或者你每次去机房都在机房电脑上装一个，实验就在机房电脑解决掉。但机房电脑每次开机都会重置，所以需要你每次做实验的时候，建立一个txt记事本，把你的SQL命令记录下来，用U盘拷走，下次就还能继续使用

课程的分数比例是50%平时分+50%期末考试。我数据库1挂了，因为只背概念但没有注意课后题的练习，还好补考的时候sap老师告诉我应该怎么去学，我大量练习课后题，最终通过了补考。课后题相当重要，SQL命令怎么写、ER图怎么画都是需要记住的，把套路摸清了以后，考试你就都可以写出来了。
